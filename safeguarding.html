About the provider

Where a placement is regulated as children’s social care or supported accommodation, concerns can also go to Ofsted. Start with Ofsted’s complaints procedure. This website does not publish an Ofsted judgement, because none was found in public sources when the page was written. Ask the registered manager for the current registration evidence.

The placing local authority remains responsible for the young person it has placed, including young people placed in Portsmouth by another council.
